# E-Commerce Web Application

## Overview

This project is a full-featured E-Commerce Web Application developed using ASP.NET Core MVC. The application provides a complete online shopping experience, including product browsing, user authentication, shopping cart management, order processing, payment integration, and administrative controls.

## Features

### Customer Features

* User Registration and Login
* Google Authentication
* Product Browsing and Search
* Product Categories
* Product Details Page
* Shopping Cart Management
* Checkout Process
* Order Placement
* Order History
* Responsive Design for Desktop and Mobile Devices

### Admin Features

* Dashboard Management
* Product Management (Create, Update, Delete)
* Category Management
* Inventory Management
* Order Management
* User Management
* Featured Product Management

### Security Features

* Authentication and Authorization
* Role-Based Access Control
* Secure Password Hashing
* Protected Administrative Routes

## Key Functionalities

### Product Management

The system allows administrators to manage products, categories, pricing, inventory, and featured products.

### Shopping Experience

Users can browse products, search by category, view product details, add items to the cart, and complete purchases.

### Authentication System

The application supports traditional login and registration as well as Google Sign-In integration.

### Order Processing

Customers can place orders and track their purchase history while administrators can manage incoming orders.

### Payment Processing

Stripe integration enables secure online payment transactions.

## Deployment

The application is deployed online and accessible through a live URL for testing and demonstration purposes.
